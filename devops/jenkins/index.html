1. Qu'est-ce que Jenkins ?

Jenkins est un serveur d'automatisation open-source qui permet aux développeurs de construire, tester et déployer leur code de manière continue. C'est le cœur de la culture DevOps, permettant de transformer un commit GitHub en une application prête pour la production en quelques minutes.

Concept clé : Jenkins surveille les dépôts Git, déclenche des builds automatiques et exécute des pipelines définies en code (Jenkinsfile).

2. Installation détaillée de Jenkins

Instructions complètes pour chaque système d'exploitation.

Prérequis : Java

Jenkins nécessite Java 11, 17 ou 21 pour fonctionner.

Ubuntu / Debian
sudo apt update
sudo apt install openjdk-17-jre-headless -y
java -version
Windows
# Télécharger Java depuis https://adoptium.net/
# Installer et configurer JAVA_HOME dans les variables d'environnement
macOS
brew install openjdk@17
sudo ln -sfn /usr/local/opt/openjdk@17/libexec/openjdk.jdk /Library/Java/JavaVirtualMachines/openjdk-17.jdk
Ubuntu / Debian (APT)
Étape 1 : Ajout de la clé et du dépôt Jenkins
curl -fsSL https://pkg.jenkins.io/debian-stable/jenkins.io-2023.key | sudo tee \
  /usr/share/keyrings/jenkins-keyring.asc > /dev/null

echo deb [signed-by=/usr/share/keyrings/jenkins-keyring.asc] \
  https://pkg.jenkins.io/debian-stable binary/ | sudo tee \
  /etc/apt/sources.list.d/jenkins.list > /dev/null
Étape 2 : Installation
sudo apt update
sudo apt install jenkins -y
Étape 3 : Démarrage du service
sudo systemctl enable jenkins
sudo systemctl start jenkins
sudo systemctl status jenkins
Accès : http://localhost:8080
Windows (Installeur MSI)
Étape 1 : Téléchargement
# Aller sur https://www.jenkins.io/download/
# Télécharger la version LTS pour Windows (jenkins.msi)
Étape 2 : Installation
  • Exécuter l'installeur en tant qu'administrateur
  • Choisir le dossier d'installation (par défaut: C:\Program Files\Jenkins)
  • Spécifier le port (par défaut: 8080)
  • Choisir le compte de service (recommandé: Run service as LocalSystem)
  • Vérifier que Java est bien détecté
Étape 3 : Vérification
# Le service Jenkins démarre automatiquement
# Ouvrir un navigateur sur http://localhost:8080
Note : Si le service ne démarre pas, vérifier dans "Services Windows" que Jenkins est bien lancé.
macOS (Homebrew)
Installation
# Installer Jenkins LTS
brew install jenkins-lts

# Démarrer le service
brew services start jenkins-lts

# Arrêter le service
brew services stop jenkins-lts

# Redémarrer
brew services restart jenkins-lts
Installation de la version stable (non-LTS)
brew install jenkins
brew services start jenkins
Accès : http://localhost:8080
Docker (Universel)

La méthode la plus rapide pour tester sur n'importe quel OS.

Lancer Jenkins avec Docker
# Télécharger et exécuter Jenkins
docker run -d \
  -p 8080:8080 \
  -p 50000:50000 \
  -v jenkins_home:/var/jenkins_home \
  --name jenkins-lab \
  jenkins/jenkins:lts

# Voir les logs (pour récupérer le mot de passe initial)
docker logs jenkins-lab
Avec Docker Compose

Créer un fichier docker-compose.yml :

version: '3.8'

services:
  jenkins:
    image: jenkins/jenkins:lts
    container_name: jenkins-lab
    ports:
      - "8080:8080"
      - "50000:50000"
    volumes:
      - jenkins_home:/var/jenkins_home
      - /var/run/docker.sock:/var/run/docker.sock
    restart: always

volumes:
  jenkins_home:
docker compose up -d
Avantage Docker : Installation propre, facile à supprimer et à reconstruire.

3. Première Configuration

Étape 1 : Déverrouiller Jenkins

Peu importe l'OS, la première étape est de récupérer le mot de passe initial :

Ubuntu / Linux
sudo cat /var/lib/jenkins/secrets/initialAdminPassword
Windows
type C:\ProgramData\Jenkins\.jenkins\secrets\initialAdminPassword
macOS (Homebrew)
cat ~/.jenkins/secrets/initialAdminPassword
Docker
docker exec jenkins-lab cat /var/jenkins_home/secrets/initialAdminPassword
Accès interface :

Ouvrir un navigateur sur http://localhost:8080 et coller le mot de passe.

Étape 2 : Installation des plugins
  • "Install suggested plugins" : Installation des plugins recommandés (Git, Pipeline, etc.)
  • "Select plugins to install" : Choix personnalisé des plugins

L'installation peut prendre quelques minutes.

Étape 3 : Création du premier utilisateur

Créer un compte administrateur pour sécuriser l'accès :

  • Nom d'utilisateur
  • Mot de passe
  • Nom complet
  • Adresse email
Étape 4 : Configuration de l'URL

Définir l'URL racine de Jenkins (par défaut : http://localhost:8080).

Jenkins est prêt ! Vous pouvez maintenant créer votre premier job.

4. Vérification de l'installation

Commandes de vérification (Linux/macOS)
# Statut du service
sudo systemctl status jenkins

# Logs Jenkins
sudo journalctl -u jenkins -f

# Ports ouverts
ss -tlnp | grep 8080
Commandes de vérification (Windows)
# Dans PowerShell (Admin)
Get-Service jenkins

# Voir les logs
Get-EventLog -LogName Application -Source "Jenkins" -Newest 10
Vérification ultime : Ouvrir http://localhost:8080 dans un navigateur.

6. Dépannage courant

Erreur : Jenkins ne démarre pas
# Vérifier que Java est installé
java -version

# Vérifier les logs
sudo journalctl -u jenkins -e

# Vérifier les permissions
sudo chown -R jenkins:jenkins /var/lib/jenkins
Erreur : Port 8080 déjà utilisé
# Trouver le processus
sudo lsof -i :8080

# Changer le port dans Jenkins
sudo nano /etc/default/jenkins
# Modifier HTTP_PORT=8081
sudo systemctl restart jenkins
Erreur : Permission denied
# Sur Linux
sudo usermod -aG docker jenkins
sudo systemctl restart jenkins

# Vérifier les permissions du répertoire
sudo chown -R jenkins:jenkins /var/lib/jenkins
Erreur : Mot de passe initial non trouvé
# Re-générer le mot de passe
sudo java -jar /usr/share/jenkins/jenkins.war --httpPort=8081
# ou via Docker
docker exec jenkins-lab cat /var/jenkins_home/secrets/initialAdminPassword
