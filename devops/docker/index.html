1. Qu'est-ce que Docker ?

Docker est une plateforme de conteneurisation qui permet d'empaqueter des applications et leurs dépendances dans des conteneurs légers et portables. Contrairement aux machines virtuelles, les conteneurs partagent le noyau du système hôte, ce qui les rend extrêmement rapides et économes en ressources.

2. Installation détaillée de Docker

Instructions complètes pour chaque système d'exploitation.

Ubuntu / Debian (Docker Engine)
Étape 1 : Nettoyage des anciennes versions
sudo apt remove docker docker-engine docker.io containerd runc
Étape 2 : Mise à jour des dépôts
sudo apt update
sudo apt install ca-certificates curl gnupg lsb-release -y
Étape 3 : Ajout de la clé GPG officielle Docker
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
Étape 4 : Ajout du dépôt Docker
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu \
  $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
Étape 5 : Installation de Docker Engine
sudo apt update
sudo apt install docker-ce docker-ce-cli containerd.io docker-compose-plugin -y
Étape 6 : Démarrage et activation
sudo systemctl enable docker
sudo systemctl start docker
sudo systemctl status docker
Étape 7 : Configuration des permissions (optionnel mais recommandé)
sudo usermod -aG docker $USER
# Déconnexion/reconnexion nécessaire après cette commande
Vérification : docker --version && docker run hello-world

Commandes de vérification
# Version de Docker

# Version de Docker Compose
docker compose version

# Informations système
docker info

# Test avec le conteneur hello-world
docker run hello-world

# Vérification des conteneurs en cours
docker ps

# Vérification des images téléchargées

4. Commandes Docker essentielles

Gestion des conteneurs
# Lister les conteneurs
docker ps          # En cours
docker ps -a       # Tous

# Démarrer/arrêter
docker start nom_conteneur
docker stop nom_conteneur
docker restart nom_conteneur

# Supprimer
docker rm nom_conteneur
docker container prune  # Tous arrêtés

# Exécuter une commande
docker exec -it nom_conteneur bash

# Logs
docker logs -f nom_conteneur
Gestion des images
# Lister les images
docker images

# Télécharger une image
docker pull ubuntu:22.04

# Supprimer une image
docker rmi image_id

# Construire une image
docker build -t nom:tag .

# Taguer une image
docker tag image_id user/nom:tag

# Pousser vers Docker Hub
docker push user/nom:tag
Docker Compose
# Démarrer les services
docker compose up -d

# Arrêter les services
docker compose down

# Voir les logs
docker compose logs -f

# Reconstruire
docker compose build

# Lister les services
docker compose ps
Nettoyage
# Supprimer conteneurs arrêtés
docker container prune

# Supprimer images non utilisées
docker image prune

# Supprimer volumes non utilisés
docker volume prune

# Supprimer tout (⚠️ attention)
docker system prune -a --volumes

5. Dépannage courant

Erreur : permission denied

Sur Linux, si vous devez utiliser sudo à chaque fois :

sudo usermod -aG docker $USER
# Déconnectez-vous et reconnectez-vous
Erreur : port déjà utilisé
# Trouver le processus utilisant le port
sudo lsof -i :8069
# ou
netstat -tulpn | grep 8069

# Changer le port dans docker-compose.yml
ports:
  - "8070:8069"  # Utilise le port 8070 à la place
Erreur : plus d'espace disque
# Voir l'espace utilisé par Docker
docker system df

# Nettoyer
docker system prune -a --volumes
Erreur : WSL 2 sous Windows
# Vérifier la version de WSL
wsl --list --verbose

# Mettre WSL 2 par défaut
wsl --set-default-version 2

# Installer une distribution Linux
wsl --install -d Ubuntu
