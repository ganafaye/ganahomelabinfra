1. Qu'est-ce que Kubernetes ?

Kubernetes (K8s) est une plateforme open-source d'orchestration de conteneurs. Elle automatise le déploiement, la mise à l'échelle et la gestion des applications conteneurisées. Originellement développé par Google, c'est aujourd'hui le standard de facto pour l'orchestration de conteneurs.

Orchestration

Gestion automatisée des conteneurs

Auto-réparation

Redémarrage automatique des conteneurs défaillants

Mise à l'échelle

Scale horizontal automatique

Multi-cloud

Fonctionne partout (on-prem, cloud, hybride)

Concept clé : Kubernetes gère des clusters de machines pour exécuter des applications conteneurisées avec haute disponibilité.

2. Architecture de Kubernetes

Composants du Control Plane (Master)
  • kube-apiserver - API REST frontale
  • etcd - Stockage clé-valeur distribué
  • kube-scheduler - Planification des pods
  • kube-controller-manager - Contrôleurs
  • cloud-controller-manager - Intégration cloud
Composants des Workers (Nœuds)
  • kubelet - Agent principal sur chaque nœud
  • kube-proxy - Gestion du réseau
  • Container Runtime - Docker, containerd, CRI-O

3. Installation de Kubernetes

Plusieurs options pour installer Kubernetes selon vos besoins.

Minikube (Cluster local mono-nœud)

Idéal pour l'apprentissage et le développement local.

Installation sur Linux
# Télécharger Minikube
curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube-linux-amd64
sudo install minikube-linux-amd64 /usr/local/bin/minikube

# Démarrer Minikube
minikube start --driver=docker

# Vérifier le statut
minikube status
Installation sur macOS
# Via Homebrew
brew install minikube

# Démarrer
minikube start

# Via binaire
curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube-darwin-amd64
sudo install minikube-darwin-amd64 /usr/local/bin/minikube
Installation sur Windows
# Télécharger l'exécutable
# https://storage.googleapis.com/minikube/releases/latest/minikube-installer.exe

# Ou via Chocolatey
choco install minikube

# Démarrer
minikube start
Kind (Kubernetes in Docker)

Cluster Kubernetes multi-nœuds dans des conteneurs Docker.

# Installer Kind
curl -Lo ./kind https://kind.sigs.k8s.io/dl/v0.20.0/kind-linux-amd64
chmod +x ./kind
sudo mv ./kind /usr/local/bin/kind

# macOS
brew install kind

# Windows
choco install kind
# Créer un fichier de configuration
cat <<EOF | kind create cluster --config=-
kind: Cluster
apiVersion: kind.x-k8s.io/v1alpha4
nodes:
- role: control-plane
- role: worker
- role: worker
EOF
K3s (Kubernetes léger de Rancher)

Distribution certifiée, idéale pour l'IoT et les environnements contraints.

# Installation serveur
curl -sfL https://get.k3s.io | sh -

# Récupérer la config
sudo cat /etc/rancher/k3s/k3s.yaml > ~/.kube/config

# Vérifier
k3s kubectl get nodes
kubeadm (Cluster multi-nœuds)

Pour déployer un cluster de production.

Prérequis :
  • 2+ machines Ubuntu (1 master, N workers)
  • 2 Go RAM minimum par machine
  • Réseau entre les machines
Installation sur toutes les machines
# Installer containerd
sudo apt update
sudo apt install -y containerd

# Configurer containerd
sudo mkdir -p /etc/containerd
containerd config default | sudo tee /etc/containerd/config.toml

# Installer kubeadm, kubelet, kubectl
sudo apt-get update
sudo apt-get install -y apt-transport-https ca-certificates curl gpg

curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.28/deb/Release.key | sudo gpg --dearmor -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg

echo 'deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.28/deb/ /' | sudo tee /etc/apt/sources.list.d/kubernetes.list

sudo apt-get update
sudo apt-get install -y kubelet kubeadm kubectl
sudo apt-mark hold kubelet kubeadm kubectl
Initialiser le master
sudo kubeadm init --pod-network-cidr=10.244.0.0/16

# Configurer kubectl
mkdir -p $HOME/.kube
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
sudo chown $(id -u):$(id -g) $HOME/.kube/config

# Installer un réseau (Flannel)
kubectl apply -f https://github.com/flannel-io/flannel/releases/latest/download/kube-flannel.yml
Rejoindre les workers
# Sur chaque worker, exécuter la commande donnée par kubeadm init
kubeadm join 192.168.1.100:6443 --token xxx --discovery-token-ca-cert-hash sha256:xxx
Docker Desktop (Windows/macOS)

Le moyen le plus simple d'avoir Kubernetes sur poste de travail.

Windows / macOS
  1. Installer Docker Desktop
  2. Aller dans Settings → Kubernetes
  3. Cocher "Enable Kubernetes"
  4. Cliquer sur "Apply & Restart"
# Vérifier
kubectl get nodes

5. Vérification du cluster

# Voir les nœuds du cluster
kubectl get nodes

# Voir tous les pods dans tous les namespaces
kubectl get pods --all-namespaces

# Voir les services
kubectl get services

# Informations détaillées du cluster
kubectl cluster-info

# Voir la configuration
kubectl config view
Premier déploiement test
# Déployer Nginx
kubectl create deployment nginx-test --image=nginx

# Exposer le déploiement
kubectl expose deployment nginx-test --port=80 --type=NodePort

# Voir le service
kubectl get svc

# Supprimer
kubectl delete deployment nginx-test
kubectl delete svc nginx-test

6. Commandes kubectl essentielles

Gestion des pods
# Lister les pods
kubectl get pods
kubectl get pods -w  # Watch mode

# Détails d'un pod
kubectl describe pod nom-pod

# Logs
kubectl logs nom-pod
kubectl logs -f nom-pod  # Follow

# Exécuter une commande dans un pod
kubectl exec -it nom-pod -- bash

# Supprimer un pod
kubectl delete pod nom-pod
Gestion des déploiements
# Créer un déploiement
kubectl create deployment nom --image=image

# Lister
kubectl get deployments

# Mettre à jour l'image
kubectl set image deployment/nom container=image:v2

# Scale
kubectl scale deployment/nom --replicas=5

# Rollback
kubectl rollout undo deployment/nom
Services et networking
# Exposer un déploiement
kubectl expose deployment nom --port=80 --type=LoadBalancer

# Lister les services
kubectl get svc

# Port-forward
kubectl port-forward pod/nom 8080:80
ConfigMaps et Secrets
# Créer un ConfigMap
kubectl create configmap app-config --from-literal=key=value

# Créer un Secret
kubectl create secret generic app-secret --from-literal=password=secret

7. Dépannage courant

Erreur : Unable to connect to the server
# Vérifier que le cluster est en marche
minikube status
# ou
docker ps | grep kind

# Reconfigurer kubectl
kubectl cluster-info

# Pour Minikube
minikube start
Erreur : CrashLoopBackOff
# Voir les logs du pod
kubectl logs nom-pod --previous

# Décrire le pod
kubectl describe pod nom-pod

# Vérifier l'image et les ressources
Erreur : ImagePullBackOff
# Vérifier le nom de l'image
# Vérifier la connexion Internet
# Sur Minikube, configurer le proxy Docker
eval $(minikube docker-env)
Erreur : Permission denied
# Vérifier le contexte
kubectl config current-context

# Lister les contextes
kubectl config get-contexts

# Changer de contexte
kubectl config use-context nom-contexte
