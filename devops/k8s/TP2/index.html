Projet 2 : Scaling & Load Balancing

Architecture Scale-Out

1. Architecture Réseau

Mise en place d'une infrastructure capable de distribuer le trafic sur 3 instances identiques pour assurer la haute disponibilité.

Flux de données :

Utilisateur (Port 31996) ➔ NodePort (192.168.49.2) ➔ Service LoadBalancer ➔ [Pod 1 | Pod 2 | Pod 3]
Le Service "web-entrypoint" :
apiVersion: v1
kind: Service
metadata:
  name: web-entrypoint
spec:
  type: LoadBalancer
  selector:
    app: web-cluster
  ports:
    - port: 80
      targetPort: 80
      nodePort: 31996

2. Validation du SI

Contrairement au port-forward, cette méthode utilise l'infrastructure native de Minikube, offrant une URL stable :

http://192.168.49.2:31996
