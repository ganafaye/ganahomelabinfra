Projet 5 : Persistance & État (PV / PVC)

Gestion durable du stockage pour applications Stateful

STATEFUL VALIDATED

1. Stratégie de Stockage

Pour dompter le cycle de vie éphémère de Kubernetes, nous avons implémenté une couche de stockage physique persistante sur le nœud Ubuntu (ThinkPad).

Le Manifeste de Stockage (PVC) :
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: mysql-pv-claim
spec:
  accessModes:
    - ReadWriteOnce # Accès exclusif au Pod
  resources:
    requests:
      storage: 1Gi
